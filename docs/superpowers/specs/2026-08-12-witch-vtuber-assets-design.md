# 새 마녀풍 버튜버 이미지셋 설계

## 목표

기존 `anime-face-*` 에셋을 보존하면서, 참고 이미지의 분위기만 차용한 독창적인 치비 마녀 캐릭터를 현재 Pixi 기반 앱에서 사용할 수 있는 투명 WebP 파츠셋으로 추가한다.

## 캐릭터 방향

- 치비 비율의 귀여운 마녀풍 캐릭터
- 붉은 계열의 긴 머리, 검정 계열 의상, 큰 마녀 모자
- 얼굴형·앞머리·모자 장식·의상 디테일은 참고 이미지와 다르게 설계
- 원본 이미지의 워터마크, 구도, 특정 장식 조합은 재현하지 않음

## 파츠 구성

각 파일은 동일한 캔버스 크기와 동일한 기준점(anchor)을 사용한다.

- `hair-back`: 뒤쪽 머리카락과 끝부분
- `body`: 몸통과 의상 기본
- `face-base`: 피부와 얼굴 기본 영역
- `ear`: 귀와 귀 주변 보정 영역
- `eye-left`, `eye-right`: 눈 흰자·홍채·속눈썹 기본
- `eyebrow`: 좌우 눈썹 기본
- `mouth`: 입 모양 교체용 기본 파츠
- `hair-front`: 얼굴 위로 내려오는 앞머리
- `hat`: 모자와 챙
- `accessory`: 모자 핀과 작은 장식

표정 파츠는 기본 파츠와 별도로 생성한다.

- 눈: `open`, `blink`, `wink-left`, `wink-right`, `happy`, `surprised`
- 입: `neutral`, `smile`, `open`, `small-o`, `sad`
- 눈썹: `neutral`, `raised`, `angry`, `sad`

## 움직임 기준

- 얼굴 전체: 좌우 회전, 상하 기울기, 미세 확대/축소
- 앞머리와 뒤쪽 머리: 얼굴보다 느린 관성으로 이동
- 모자: 머리 회전량의 일부만 따라가도록 별도 보정
- 눈과 입: 얼굴 기준점에 고정하고 표정 파츠만 교체
- 각 파츠의 외곽에는 다른 파츠와 합성할 수 있는 여유 영역을 둔다.

## 산출물

새 파일은 `public/vtuber-witch/` 아래에 저장한다. 기존 `public/anime-face-*` 파일은 변경하지 않는다.

- 모든 파일: RGBA WebP, 동일한 1024×1024 캔버스
- 배경: 완전 투명
- 파일명: `witch-<part>-<variant>.webp`
- 메타데이터와 워터마크는 포함하지 않음
- 기본 합성 프리뷰 1장과 파츠 목록 문서를 함께 제공

## 검증

- 모든 파츠가 동일한 크기와 알파 채널을 갖는지 확인
- 투명 모서리와 가장자리 색 번짐 확인
- 기존 에셋의 git diff가 없는지 확인
- WebP 디코딩 가능 여부와 파일 목록 확인
- 앱 연결 전에는 생성물만 검토하고, 연결 코드는 별도 승인 후 수정
