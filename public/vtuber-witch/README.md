# Witch VTuber asset set

Original chibi witch-style VTuber layers for the Pixi compositor.

All files use a 1024×1024 canvas, RGBA WebP encoding, transparent pixels outside the requested part, and the same face/canvas anchor. The asset set is independent from the existing `public/anime-face-*` assets.

## Composition order

`hair-back` → `body` → `face-base` → `ear` → `eye-left` → `eye-right` → `eyebrow` → `mouth` → `hair-front` → `hat` → `accessory`

## Variants

- Eyes: `open`, `blink`, `wink-left`, `wink-right`, `happy`, `surprised`
- Mouth: `neutral`, `smile`, `open`, `small-o`, `sad`
- Eyebrows: `neutral`, `raised`, `angry`, `sad`

The character takes only broad mood and genre cues from the supplied reference. It does not reproduce the reference character, watermark, exact composition, or distinctive accessory arrangement.
